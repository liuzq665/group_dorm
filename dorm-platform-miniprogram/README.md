# 学生微信小程序端

目录 `dorm-platform-miniprogram` 是独立的原生微信小程序，保留现有网页端，并复用 Spring Boot 的 `/api/v1` 接口、Bearer Token 认证和文件上传接口。

## 导入和运行

1. 保持后端运行在 `http://127.0.0.1:8080`，并确认它连接 `dorm_platform_first_ysz_test`。
2. 打开微信开发者工具，选择“导入项目”，目录选择本目录。
3. `project.config.json` 的 `appid` 为空：使用测试号或你自己的合法 AppID 填入微信开发者工具的项目设置；本仓库不提供或伪造 AppID。
4. 开发者工具中勾选“忽略合法域名、web-view（业务域名）、TLS 版本以及 HTTPS 证书”。本地 HTTP 调试需要该选项。
5. 默认地址在 `utils/config.js`：`http://127.0.0.1:8080/api/v1`。开发者工具模拟器可用本机回环地址；真机须改为电脑可访问的局域网 IP 或 HTTPS 地址，例如 `http://192.168.x.x:8080/api/v1`。

不要把数据库密码、登录令牌或生产地址写入项目文件。小程序登录令牌只保存在微信本地存储中，收到 401 会自动清除并回到登录页。

## 已接入页面

- 登录、退出、登录失效处理
- 工作台、我的住宿、舍友、消息列表与已读
- 报修列表、详情、新建、编辑、提交、撤销、确认、评价、申请重修
- 留宿批次、多个不重叠日期段、保存、提交、撤回、修改、重新提交、审核记录
- 个人资料查看与更新、修改密码

留宿开放区间由后台批次的单一开始/结束日期控制；学生日期段允许多个，但小程序和后端均拒绝重叠或共享边界日的日期段。
