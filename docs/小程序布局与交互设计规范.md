## 1. 目标与适用范围

### 1.1 目标

1. **风格统一**：四端小程序页面共用一套颜色、字号、间距、圆角、状态标签与卡片结构，不再出现"每个页面各自写一套"的情况。
2. **全局可用**：规范沉淀为 `app.wxss` 的设计令牌与组件类，任何新页面直接引用类名即可获得统一外观，不需要复制样式。
3. **移动端可用**：所有列表、详情、筛选、操作区在 320dp～430dp 宽度下完整可读，**禁止横向滚动**、**禁止操作按钮换行**（G-03、G-04）。
4. **长页面收敛**：通过筛选吸顶、分类 Tab、分区折叠、分页/加载更多，避免"一长到底"。
5. **口径一致**：状态文案、消息来源、空值（`-`）、时间格式四端统一，页面只做展示，不各自定义业务口径。

### 1.2 适用范围与边界

- **本版实施**：全局设计令牌与组件（`app.wxss`、`templates/ui.wxml`）、学生端页面、维修人员端页面、以及学生/维修共用的消息中心。
- **不在本版实施**：宿管端、系统管理员端页面结构改造（业务归属 A，样式类保持向后兼容，A 可直接复用本规范）；Web 管理后台（A 负责）。
- **兼容约束**：`app.wxss` 现有类名（`.page`、`.hero`、`.card`、`.row`、`.label`、`.value`、`.status`、`.primary` 等）必须保持存在且语义不变，宿管端/管理员端小程序页面无需改动即可继续正常显示。

## 2. 设计原则

| 原则 | 说明 | 对应验收 |
| --- | --- | --- |
| P1 一屏一主题 | 每个页面只有一个主任务，页面顶部用一句话说明当前范围（如"只显示派给本人的工单"）。 | G-01 |
| P2 信息分层 | 卡片内固定顺序：标题 + 状态 → 业务字段 → 时间/备注 → 操作区。用户视线自上而下，不来回跳。 | G-01、G-02 |
| P3 不换行、不横滑 | 操作按钮等宽横排；长文本必须 `overflow-wrap:anywhere`；筛选区/标签区用换行（`flex-wrap`）而非横向滚动容器。 | G-03、G-04 |
| P4 数据可追溯 | 页面展示的数量必须来自接口真实统计或由同一批列表数据推导，不允许写死或"大概显示"。 | G-07 |
| P5 空闲不隐藏 | 业务分类（待接单、待确认等）固定展示，当前无数据时显示空态，不因无数据隐藏分类。 | 3.3、4.4 |
| P6 修改不破坏 | 只改样式类与页面结构，业务请求路径与状态机保持不变；每次修改回归该端原有功能。 | G-06 |
| P7 密度克制 | 列表卡片只保留“标题+状态 / 1~3 行关键信息 / 时间+入口”，完整信息放详情；单屏主信息不超过 3~5 组。 | G-02、G-07 |

### 3.4 圆角与层级（v1.1 更柔和）

| 令牌 | 值 | 用途 |
| --- | --- | --- |
| `--radius-s` | 6rpx | 状态标签、小标签、附件项 |

**卡片视觉**：白底 + `--shadow-card` + `--radius-l`，不再使用 1rpx 硬描边；仅输入框、描边按钮保留发丝边框。分割线使用 `--divider`（更淡）。

### 3.5 触控与安全区

- 主按钮高度 `68rpx`，行内小按钮高度 `56rpx`，最小可点击高度不低于 `56rpx`。
- Tab 高度 `52rpx`（可点击区域由 padding 撑到 56rpx 以上）。
- 底部固定 tabBar 高度 `calc(106rpx + env(safe-area-inset-bottom))`；页面底部统一预留 `calc(136rpx + env(safe-area-inset-bottom))`，保证滚动到底部时最后一条内容不被导航栏遮挡（含刘海屏安全区）。
- 吸顶元素 `top: 0`（页面 `navigationStyle` 默认，不含自定义导航）。
- **覆盖原生 button 宽度与居中**：微信原生 `button` 默认 `wx-button:not([size="mini"]){width:184px}` 且为 block 布局（单行文字贴顶），必须在 `app.wxss` 同时设置 `button:not([size="mini"]){width:auto}` 与 `button{display:flex;align-items:center;justify-content:center}`；需要整行时使用 `button.full-width` 或 `.action-bar` 等宽布局。

## 4. 页面骨架与栅格

### 4.1 标准页面骨架

```
.page                        ← 页面容器：左右 28rpx，底部 136rpx
  .page-heading              ← 可选：标题 + 一句话说明 + 主操作（单行，说明换行）
  .sticky-filter             ← 可选：筛选/分类区（吸顶）
  .record-list / .card       ← 内容区
  .pager / .load-more        ← 列表分页或加载更多
  .modal-mask                ← 弹层（表单/详情）
```

### 4.2 页面类型与必备结构

| 页面类型 | 示例 | 必备结构 |
| --- | --- | --- |
| 工作台/首页 | `pages/home` | Hero → 指标卡（仅维修/宿管/管理员）→ 服务入口宫格 |
| 列表页 | `pages/repairs`、`pages/messages`、`pages/stays` | 标题 → 筛选/分类 → 列表 → 分页 → 空态 |
| 详情页 | `pages/repair-detail`、`pages/stay-detail` | Hero 摘要 → 详情字段卡 → 记录卡（按时间）→ 操作区（底部） |
| 表单页 | `pages/repair-form`、`pages/stay-form` | 表单卡 → 必填提示 → 操作区（保存/提交等宽） |
| 个人中心 | `pages/mine`、`pages/accommodation` | Hero → 资料卡 → 功能卡 → 退出 |

**底部导航（tabBar）**：按角色显示可用入口——学生（首页/报修/留宿/消息/我的，5 个）、维修人员（工作台/维修任务/消息/我的，4 个）、宿管（工作台/报修审核/留宿审核/消息/我的，5 个）、系统管理员（工作台/报修管理/留宿管理/消息/我的，5 个）。当前页必须高亮且只高亮一个入口：顶部短指示条 + 图标浅色底 + 文字加粗变色（详见 C-16）。

### 4.3 栅格与宽度约束

- 栅格：单列流式；指标卡为 2 列（`grid-template-columns: repeat(2, minmax(0, 1fr))`）。
- 所有 flex/grid 子项必须声明 `min-width: 0`，避免长文本把容器撑开导致横向滚动。
- 详情字段采用 `label 固定宽 + value 自适应` 的两列布局：label `168rpx`、gap `16rpx`、value `min-width:0`、`word-break:break-word`。
- 列表卡片内不使用横向滚动的表格；业务字段以"标签 + 值"行展示。

## 5. 布局专项规则

### 5.1 禁止横向滚动（G-03）

1. 全局：`page { overflow-x: hidden; }`；任何容器不得设置 `white-space: nowrap` 于长文本。
2. 禁止使用 `scroll-view scroll-x` 承载筛选/分类 Tab，统一使用 `flex-wrap: wrap` 的多行标签布局。
3. 长工单号、长文件名、长姓名统一 `overflow-wrap: anywhere`；文件名超出用省略号 + 详情查看。
4. 图片类附件不直接铺满卡片，使用附件行（名称 + 预览）展示。

### 5.2 操作按钮不换行（G-04）

1. 卡片操作区使用 `.action-bar`：`display:flex; flex-wrap:nowrap; gap:12rpx;`，每个按钮 `flex:1 1 0; min-width:0;` 且 `white-space:nowrap`。
2. 同一操作区最多 3 个按钮；超过 3 个时，主操作常驻，其余收进"更多操作"（`wx.showActionSheet`），避免挤压。
3. 按钮文案限制 6 个汉字以内（"确认完成并评分"→"确认完成"），完整说明放二次确认弹窗。
4. 详情页主操作固定在内容末尾的 `.action-bar`，不浮动遮挡内容。

### 5.3 列间距与文字遮挡（G-01、G-02）

- 卡片内字段行：`padding: 10rpx 0`，`border-bottom: 1rpx solid var(--divider)`，最后一行去边框。
- 标题与状态标签同一行：标题 `flex:1; min-width:0`，状态 `flex:none`，间距 `12rpx`；状态标签最大宽度 `40%`，超长换行居中。
- 不允许绝对定位放置业务文本（装饰角标除外）。

### 5.4 长页面收敛

| 手段 | 规则 |
| --- | --- |
| 筛选吸顶 | 列表页筛选/分类区使用 `.sticky-filter`（`position: sticky; top: 0; z-index: 15`），背景 `--page-bg`，下方留 `1rpx` 分隔 |
| 分类 Tab | 分类数量 ≤ 10，多行排列；选中项使用 `--brand-600` 实底 |
| 分区折叠 | 同一页面出现 3 组以上记录列表时，使用 `.collapse`（标题 + 条数 + 展开箭头），默认展开有数据的组 |
| 分页 | 单页最多 10 条；数据多时显示 `.pager`（上一页 / 页码 / 下一页），页码稳定不跳动 |
| 加载更多 | 仅消息中心等"流式"列表可选；与分页二选一，不混用 |

### 5.5 吸顶偏移与安全区

- `.sticky-filter { top: 0; }`（页面无自定义导航）。
- 底部操作区页面：`.page` 底部 padding ≥ 内容高度 + 24rpx，避免被 tabBar 遮挡。

### 5.6 信息密度（v1.1）

目标：**单屏信息不过密，用层级代替堆叠**。

| 场景 | 规则 |
| --- | --- |
| 列表卡片 | 1 行标题+状态 + ≤2 行关键字段 + 1 行时间/评分与入口；总数不超过 4 行 |
| 长文本 | 列表正文最多 2 行截断（`-webkit-line-clamp:2`），完整内容进详情 |
| 冗余字段 | 无附件的“附件：-”、无楼栋的“楼栋：未指定”等占位信息不在列表展示，只在详情显示 |
| 指标卡 | 单页最多 4 个核心指标；其余数量放入折叠标题条数或头部说明（如“累计完工 26 单 · 收到评价 20 条”） |
| 记录分组 | 3 组以上记录使用折叠（`.collapse`），默认只展开有数据且当前最相关的组 |
| 详情页 | 字段无分隔线、靠行距分组；6 组以上记录用折叠收敛 |
| 主操作 | 每屏只保留 1 个主按钮；页面头部操作使用 `compact-button`，不与标题争夺视觉重心 |

## 6. 统一组件规范

所有组件以类名或模板（`templates/ui.wxml`）提供，页面不得自行重定义同名样式。组件尺寸单位统一 `rpx`。

### C-01 页面标题 PageHeader

```html
<view class="page-heading">
  <view class="grow"><text class="heading-title">我的报修</text><text class="heading-sub">查看处理进度与维修记录</text></view>
  <button class="primary compact-button">新建</button>
</view>
```

- 标题 `34rpx/650`，说明 `23rpx/--text-2`，主操作在右侧，`gap 16rpx`。
- 说明文字过长时最多两行，超出省略。

### C-02 筛选栏 FilterBar

```html
<view class="filter-bar">
  <input class="filter-input" placeholder="按工单号搜索" />
  <button class="outline filter-action">查询</button>
</view>
```

- 单行：输入框 `flex:1; min-width:0`，按钮 `flex:none`，高度 `66rpx`。
- 需要多个筛选条件时，第二行使用 `.filter-row`（picker + 按钮），不把 3 个以上控件塞进一行。
- 查询必须重置到第 1 页；筛选条件在页面返回后保留（存于 `data.filters`）。

### C-03 分类 Tab Tabs

```html
<view class="tabs"><view class="tab active">全部</view><view class="tab">待审核</view></view>
```

- 多行排列（`flex-wrap: wrap`），`gap 8rpx`，高度 `52rpx`，字号 `23rpx`。
- 选中：`background: var(--brand-600); color:#fff`；未选中：`background:#E7ECEA; color:#52625F`。
- 分类固定展示，不因无数据隐藏；分类条目右上角可显示数量（如 `待接单·3`）。

### C-04 状态标签 StatusTag

```html
<text class="tag tag-warning">待接单</text>
```

| 语义 | 类名 | 颜色 |
| --- | --- | --- |
| 待处理/待确认/待接单 | `.tag-warning` | `--warning` / `--warning-bg` |
| 已完成/已通过/已确认 | `.tag-done` | `--success` / `--success-bg` |
| 异常/待人工/已撤销 | `.tag-danger` | `--danger` / `--danger-bg` |
| 进行中/审核中 | `.tag-info` | `--brand-600` / `--brand-50` |
| 草稿/已归档 | `.tag-muted` | `--text-2` / `#EDF1EF` |

- 高度 `40rpx`，内边距 `0 12rpx`，圆角 `4rpx`，字号 `22rpx`，`flex:none`。
- 状态文案必须取自 `utils/format.js` 的统一映射，不允许页面写死文案。

### C-05 列表卡片 RecordCard

```html
<view class="record-card" bindtap="detail">
  <view class="record-head">
    <text class="record-title">卫生间水龙头漏水</text>
    <text class="tag tag-warning">待接单</text>
  </view>
  <text class="record-meta">WX202611110001 · 水暖维修</text>
  <text class="record-meta">明德二号楼 102 · 张一</text>
  <view class="record-foot"><text class="record-time">更新于 2026-11-11 10:20</text></view>
</view>
```

## 8. 交互规范

| 场景 | 规范 |
| --- | --- |
| 加载中 | 列表骨架/文案"正在加载…"居中；按钮加载使用 `loading` 属性并禁用重复点击 |
| 加载失败 | `wx.showToast({icon:'none'})` 显示后端 message；保留页面已有数据，不清空 |
| 空态 | C-08；筛选导致空时提示调整筛选 |
| 危险操作 | `wx.showModal` 二次确认，确认按钮文案明确（"确认提交""确认撤销"） |
| 必填校验 | 前端校验 + 后端 message 兜底；提示具体字段，不用"操作失败"泛提示 |
| 表单默认值 | 评分类默认 5 分；日期类默认为空，必须显式选择 |
| 返回刷新 | 详情页 `onShow` 重新拉取，保证列表与详情状态一致 |
| 权限变化 | 401/403 统一提示并返回登录或停留在无权限提示 |
| 分页 | 切换分类/筛选条件后重置到第 1 页 |
| 防重复提交 | 提交中禁用操作按钮（`actionBusy`），成功后再恢复 |

## 9. 文案规范

1. 按钮：动词 + 对象，≤6 字（"提交审核""确认完成""申请延期"）。
2. 标题：名词短语，≤10 字；页面说明 ≤20 字。
3. 状态：使用第 7 节统一文案，禁止"已维修/维修完成/已完成"混用同一状态。
4. 单位：数量后不加空格（`3 条`），日期不加"号"。
5. 不使用技术术语（`PENDING_ACCEPT`、`DISPATCH`）直接展示给用户；派单状态、审核结果、延期结果等枚举必须经 `utils/format.js` 的 `dispatchText/resultText/statusText` 映射为中文。
6. 错误提示面向用户描述下一步（"请填写拒单原因"）。

## 10. 验收清单（对应 G-01～G-08）

| 编号 | 检查项 | 检查方法 |
| --- | --- | --- |
