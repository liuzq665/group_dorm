## 四、建议走查路线

1. **报修主链路**：学生建单（需选故障分类、可上传照片）→ 提交 → 宿管“审核通过”（自动派单）→ 维修人员“接单” → “提交维修结果”（必须传现场照片）→ 学生“确认完成 + 1~5 分评价与文字” → 工单归档；中途可试“申请延期 → 宿管审核 → 完工”。
2. **驳回/撤销/重修**：宿管审核驳回（工单转待修改，可在期限内编辑重提）；学生撤销（未派单时）后“重新提交”；学生对已维修工单“申请重修”→ 宿管审核通过 → 进入手动派单池 → 宿管强制派单。
3. **留宿**：学生选批次 → 填日期（须在开放区间内）→ 上传材料（至少 1 份）→ 提交 → 宿管先“进入审核”锁定 → “审核”（通过或驳回并给重交截止）→ 驳回后学生在截止前编辑重交。
4. **角色视野/消息**：四角色分别登录看首页入口、业务列表分页与状态筛选、消息中心来源与未读数、维修人员“维修记录/统计”、管理员用户与楼栋管理。
